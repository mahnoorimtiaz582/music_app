# 🎵 Music Player Pro

A professional music player app built with Next.js, TypeScript, and Tailwind CSS.

## ✨ Features
- 🎵 Play/Pause music
- 💙 Blue light animation
- ❤️ Favorites with local storage
- 🔍 Search songs
- 📱 Fully responsive

## 🛠️ Tech Stack
- Next.js 16
- TypeScript
- Tailwind CSS
- Lucide React Icons

## 🚀 How to Run
```bash
npm install
npm run dev
